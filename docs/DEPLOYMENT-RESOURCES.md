## 发布前检查

- 完成R02、R07–R12最终主交互及对应回归，不因已有领域测试通过就宣布全部完成。
- npm ci、npm test、typecheck、build、迁移、本地和线上E2E分别通过；不能用语法检查替代构建。
- 复核原生访问身份，OWNER_SUBJECT_ID与私有受众；多家庭仍只有方案，不能直接开放陌生用户。
- 核对所有密钥在运行时安全配置、前端与源码ZIP没有敏感数据；不要上传本机.env.local。
- 使用同一Sites源码仓库的真实推送SHA保存版本再发布，保留私有访问；当前没有可声称已发布的版本。
- 部署后验证D1原子批次/恢复上限、SSE转发/超时、模型实际额度、缓存过期与后台任务幂等。
- 用户要求的独立GPT-6.1 Sol最终审核尚未完成，后续单独执行。

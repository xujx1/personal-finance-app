# 部署资源与边界

现行开发操作见[开发与验证](DEVELOPMENT.md)，权限和资料处理见[安全说明](../SECURITY.md)。此表描述源码所需资源，不声明任何线上资源已经验收。

| 资源 | 用途 | 验证边界 |
| --- | --- | --- |
| Node.js 24、npm及锁文件 | 开发、Node SQLite测试、构建 | 环境下限见package.json；测试建议Node 24 |
| Vinext、React、TypeScript、Vite | 网站与服务端工程 | 以锁文件版本为准 |
| Sites登录与可信边缘 | 提供认证身份头 | 自部署必须阻止伪造身份头，不能直接信任客户端请求 |
| Cloudflare D1，绑定DB | 家庭账本、草稿和审计 | 使用增量迁移；不重写已应用迁移 |
| ChatGPT会话与已连接MCP | 分析、搜索、图片理解、工作流 | 网站登录不等于模型授权；能力取决于会话 |
| 运行时所有者配置 | 受信任所有者与首次家庭绑定 | 只在安全运行时维护，公开示例留空 |
| ATTACHMENT_KEY（可选） | 加密保存票据 | 独立32字节base64url密钥；迁移已存附件须保留原密钥 |
| 行情、汇率HTTPS来源 | 参考报价与换算 | 保留来源及时间，失败不伪造实时值 |
| Chrome、Playwright（开发可选） | 浏览器检查和演示截图 | 只使用隔离数据，不写生产测试流水 |
| 受保护的任务执行器（按需） | 周期检查与提醒 | 需要单独验证调度、权限与幂等 |

当前流程不要求NEW_API_*、TAVILY_API_KEY或旧站内推理OAuth配置。既有备份服务端代码不表示产品提供恢复入口。站点受众、部署标识、密钥和费用由各部署自行维护，不在公开文档中记录。

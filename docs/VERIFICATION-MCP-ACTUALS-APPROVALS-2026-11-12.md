# MCP实际消费及我的审批单验收

日期：2026-11-12；分支：codex/chatgpt-mcp-skills。

## 结果

- 实际消费沿用cashflow草稿，可关联原预算planId。提交不记账；研究记录显示固定关联计划、预算与已支付/消费，用户可核对实际金额、日期、付款成员/账户及余额覆盖，确认后才生成PAYMENT并同步计划实付、流水和现金。
- prepaymentId抵扣同计划原预付资产，不再扣银行；余额已含的历史实际付款只补关联记录，不再次扣现。错误成员/计划/预付款、旧审批依据、未来日期、超额抵扣和重复采用受控。贷款本金及证券买入不能通过消费草稿替代。
- list_my_approvals按认证身份只读查询待我审批、我发起、已处理或本家庭全部，提供状态/关键词/计划日期筛选、当前审批版本、本人意见、家人进度和详情链接。分页固定账本及家庭成员版本，历史意见不代表当前版本批准。
- 新增family-finance-approvals，消费与图片说明覆盖实际消费和预付抵扣。公共安装包1.3.0含七个通用入口；保留旧五/六个历史包、定制正文及原有备份策略。

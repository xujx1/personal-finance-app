- N001：提供真实可执行的 `npx <本站公开tgz地址> install`。公开包仅包含五个通用入口与无依赖安装器；家庭维护正文始终经认证 MCP 读取。无需用户提供 npm 发布账号。安装只更新这五份 SKILL.md，校验完整性，备份被替换版本，不改认证或其他 Skill。

- N004：确认现有 MCP 全历史流水与周期候选、周期草稿和人工采用完整链路。以两个月实际模拟流水验证；不足历史时如实返回零候选，保留既有四条规则。

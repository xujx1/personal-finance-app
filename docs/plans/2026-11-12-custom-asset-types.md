# 家庭资产类型与目标选择实施计划

**Goal:** 账户操作归入头像；设置只维护目标；家庭自定义资产类型驱动资产页与目标下拉选择。

**Architecture:** 保留现金、基金、股票、贷款等固定账务性质，增加独立的家庭资产类型字典，通过 metadata.assetTypeId 关联。默认字典由服务端共享领域模型提供，既有家庭无需手工逐条创建，首次维护保存家庭版本；读取不新增账本修订或改变金额。目标 v3 支持可增删的下拉目标行，同时兼容原四组合 v2 及 400 万、月 15000 的已存配置。

**Tech Stack:** 现有 React / TypeScript / D1 / MCP，原分支原站点。

## 有效需求与取舍

- B001：右上角圆形头像成为账户菜单，显示当前名称、邮箱、家庭与权限及退出；键盘/触屏可用。设置页只作目标设置。
- B002：资产页维护家庭类型，初始化银行现金、定期、国债、股票、证券指数ETF、基金、宽基指数基金、贵金属基金、贵金属、房产、贷款、其他与预付款类型。可以新增、改名和停用；在用或被目标引用不能停用。账务性质创建后不变，重命名不改历史或余额。
- B003：资产类型选择贯穿已有资产编辑、MCP已有资产草稿和首次真实买入。资产页页签/名称/金额取家庭字典；旧账户按原性质与明确分类推导默认类型。保留家庭归属与同币种现金规则，系统类型与预付款不允许用户伪造。
- B004：目标从四个固定输入改成可增删下拉行；选项含原四组合和家庭启用的非房产资产类型。重复或交叉覆盖禁止，单项和总额精确到分。原配置保留到用户保存；新目标按选择类型归集，不重复计算。房产、贷款、预付款继续排除本次储蓄总目标。
- B005：提供 ChatGPT 新会话实际测试说明，区分本地结构化样本与真实 AI/搜索/插件链路；不创建未经明确要求的新用户聊天或生产测试预算。

## 安全与测试

字典作为家庭文档隔离，仅管理员可维护。类型 ID 必须来自当前家庭字典并匹配账户性质；跨家庭 ID、将基金伪装现金、修改贷款性质、重复目标均拒绝且不写入。自动回归使用独立模拟家庭；生产不做测试交易、不修改已存目标金额。

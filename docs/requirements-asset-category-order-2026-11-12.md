# 资产分类按金额降序

资产与贷款页的分类金额卡片和快速选择下拉，统一按当前成员范围、当前持有资产的人民币已折算汇总金额从大到小排列；“全部”固定最前。金额相同沿用类型字典顺序，零金额类别在后，无已折算金额但含待折算资产的类别再置后，保留未折算提示。贷款沿用页面展示的正数余额排序，不改统计口径。

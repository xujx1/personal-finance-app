# 产品界面国际化与关键案例

[English](UI-I18N.en.md) · [使用指南](USER-GUIDE.md) · [完整操作手册](PRODUCT-MANUAL.md)

本次实现作用于产品本身。默认“自动”展示币种随语言切换：英文为美元 USD，中文为人民币 CNY；可在顶栏手动指定 USD 或 CNY，手动选择优先于语言。主界面顶栏与独立“加入家庭”页提供 **中文 / English** 切换，覆盖导航、表单、系统分类、审批和草稿状态、提示与校验错误、日历和报告展示。

## 操作流程

1. 打开产品，在顶栏语言选择器选择 **English**。加入家庭之前也可以切换。
2. 查看财务总览、资产与贷款、研究记录、预算、现金流水、生活日历、周期收支、月报与预测；头像菜单中的家庭管理、会员权益、目标设置和工作流也使用当前语言。
3. 打开记账或核对表单，检查标签、选项和提示。语言切换不清空输入、不提交表单。
4. 在“展示币种”选择“自动 / USD / CNY”。自动模式下切换英文即以美元展示汇总、估值、预算、目标与预测；手动币种不随语言变化。
5. 刷新和同源新标签页保留语言与币种选择。原币流水、输入框及交易数量不变。

首次进入优先使用已保存的选择，其次使用浏览器支持的首选语言，最后回退中文。语言偏好只存为本机 `family-finance.locale`，展示币种另存于 `family-finance.display-currency`，两项均不写入账本。浏览器禁止存储时仍可在当前页面切换。其他标签页的语言选择通过存储事件同步。

## 数据边界

| 内容 | 切换后的行为 |
| --- | --- |
| 导航、按钮、表单标签、系统枚举、已收录错误 | 显示对应语言 |
| 系统默认资产类型、默认家庭共用归属 | 显示对应语言；ID 保持不变 |
| 自定义/改名资产类型、成员昵称、账户和计划名称、备注 | 保留原文，包括恰好与界面词语同名的名称 |
| 历史研究、AI分析、月报复盘正文、来源摘录 | 保留原文，避免翻译改变历史证据 |
| 账本金额、CNY/USD、整数分、交易数量、版本和权限 | 原始数据保持不变；只读汇总按展示币种折算，不触发真实换汇或交易 |
| 日历和报告日期 | 标题按语言显示；业务日期、日期输入值及北京时间口径不改变 |
| 新发起的英文 ChatGPT 任务 | 附带英文回复要求；原始名称、金额和日期继续保留 |

切换语言不会触发保存或审批。未知服务错误保留原始信息；新增错误应补充英文目录。登录平台及 ChatGPT 自身页面的语言由相应服务控制。

## 实现与维护

- `components/I18n.tsx` 提供每个 React 根独立的语言上下文、切换器、金额和日期入口；不使用可串扰用户的全局语言变量。
- `src/domain/i18n.mjs` 负责语言协商、插值、已知系统消息、精确整数分格式化和默认类型标签。只向它传应用拥有的界面文字；不要把任意记录名称交给通用翻译函数。
- `src/domain/display-currency.mjs` 使用 USD→CNY 参考汇率，CNY→USD 时除以该汇率。整数分与十二位汇率精度通过 BigInt 计算，最终金额只舍入一次；美元资产直接以原币加入美元汇总，避免先转人民币再转回美元。缺失或无效汇率时，已知原币继续展示，未折算项计数；完全不能折算的汇总为未知，不能显示成零。
- `src/i18n/en.json` 使用中文源文案作为键。新增界面文案应同时添加英文，插值参数必须保持一致。
- 表单选项的 `value` 使用稳定业务值；显示文字单独翻译，禁止依赖翻译后的选项文字作为提交值。
- 涉及金额 React 节点的插值使用 `UiMessage`，保留金额隐藏组件，不把节点转成字符串。
- 单日日期按 UTC 格式化以保留原日期；实际业务“今天”、月度范围和时间戳仍沿用原北京时间规则。

## 展示币种关键案例

| 编号 | 场景与验收点 | 当前证据 |
| --- | --- | --- |
| FX-01 | 英文自动 USD，中文自动 CNY；手动选择优先，恢复“自动”后继续跟随语言 | 规则与 React 上下文自动化通过；浏览器持久化待运行 |
| FX-02 | 示例参考汇率 1 USD = 7.1 CNY 时，CNY 7,100 显示约 USD 1,000；反向转换正确 | 自动化通过；此为测试汇率，不是当前市场报价 |
| FX-03 | 正负半分、十二位汇率、安全整数上限、未知金额与不支持币种 | 自动化通过，不溢出或伪造 1:1 |
| FX-04 | 汇率缺失、来源或日期无效；混合账户中原有美元余额仍可统计 | 自动化通过，未折算项明确标记 |
| FX-05 | 旧参考汇率仍保留原日期、来源及旧汇率提示；刷新失败不得冒充新报价 | 日期、旧状态与实际提示组件自动化通过 |
| FX-06 | 两种展示币种下，交易表单全部 input/option 值、账本与已存预算保持一致 | 实际表单、预算组件与数据不变性自动化通过 |

汇率区域显示来源与报价日期，折算金额为参考展示。历史月报的折算使用当前参考汇率，不假造历史汇率；原币明细仍用于核账。养老金等受限账户的展示额同时保留原始 CNY 参考，不改变人民币年度额度。原币成交价、输入字段与历史研究原文继续保留原币。

# 接续开发

当前架构为 ChatGPT + MCP + 工作流，网站负责草稿核对、家庭审批、记账和展示。旧站内模型配置、密集发布流水和个人财务场景不再作为接续入口。

1. 阅读[文档导航](README.md)和[当前需求](requirements-latest.md)。
2. 按[开发与验证](DEVELOPMENT.md)安装锁文件依赖并运行检查。
3. 从[使用指南](USER-GUIDE.md)核对业务路径；MCP契约见[工作流说明](CHATGPT-MCP-SKILLS.md)。
4. 发布前完成[安全检查](../SECURITY.md)；托管身份、生产D1和真实ChatGPT另行验证。

本地适配器使用模拟身份，只可用于本机。站点身份由维护者私下配置；不要把别人的部署元数据或账本用作新部署默认值。生产数据和附件密钥须单独安全保管。

# 预算计划：家庭拒绝及修改

> 历史阶段记录：下文“仅本地/未发布”指2026-11-13执行范围；2026-11-16后续受控发布及复测见[最新验收](RELEASE-ACCEPTANCE-2026-11-16.md)，公开插件仍见[发布门槛](PUBLIC-PLUGIN-RELEASE-2026-11-16.md)。

用户最新要求：页面名为“预算计划”（覆盖此前“预算与支出”）；家庭成员能够拒绝预算、修改计划，修改后重新家庭审批。本轮仅本地开发与测试，不发布，不操作真实账本。

1. 当前有效家庭登录成员可以对待审批计划同意或拒绝，拒绝须填写原因。拒绝结束本轮审批，不能再按旧版同意；修改后发起新一轮。
2. 家庭成员可修改同家庭未结束计划的名称、日期、备注、预算、消费清单及行程；限定专用接口，不扩大资产、流水或家庭管理权限，不允许改计划归属、伪造审批、修改原始付款账户。
3. 修改必须确认当前计划版本并增加版本号，保存后所有有效家人的意见清空，包括修改者；原版及审批意见保留追溯。全员重新同意前不计正式预算、不同步生活日历、不允许新增付款。既有付款及预付款结算保留。
4. 拒绝、修改、查询均受家庭隔离、成员有效性、账本和计划版本校验保护；旧审批链接显示当前版本，旧请求不能批准新版本；重复请求不得重复操作。
5. 网站、导航、分享、相关引导及中英文文案使用新名称。拒绝原因、修改入口和当前审批进度在详情可见；ChatGPT审批查询可读拒绝状态，但不代审批。

不变：其他家庭看不到记录；成员不能借此修改现金、资产、贷款余额，不能自动交易或扣款。审批修改只由网站已登录成员主动提交。

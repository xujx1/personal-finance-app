# 当前需求摘要

更新：2026-11-13。公开文档只记录规则和状态，不记录个人财务配置或生产操作回执。完整编号保留在[需求规范](requirements-consolidated-2026-11-12.md)，按[文档导航](README.md)查后续专项修订。

## 当前协作方式

ChatGPT处理消费、投资、图片、周期归并和月度总结；MCP读取授权家庭依据并保存待核对草稿；网站负责核对、家庭审批、实际记账和展示。旧站内模型、搜索Key与推理OAuth配置不再是当前使用要求。网站登录与ChatGPT会话连接分别检查。

## 业务口径

| 范围 | 当前要求 |
| --- | --- |
| 家庭权限 | 非成员、其他家庭、已移除成员不能读取本家庭财务；管理员一般写入，成员共同查看并各自审批预算 |
| 成员归属 | 登录成员与记账档案分开；账户、现金、资产、贷款保留归属，转移管理员不转移资产所有权 |
| 建档 | 按已有数据逐步补成员、类型、余额日期、目标、规则；未知可跳过，不覆盖现有账本，不补造历史 |
| 草稿核对 | 七类同步草稿集中研究记录，可筛选、搜索、分页；PENDING可同ID版本续改，已处理只读 |
| 消费预算 | 可编辑费用和行程，区分报价、计算、预留及未知；采用后家庭审批，全体同意才成为正式预算及日历计划 |
| 实际消费 | 发生后核对实际金额、日期、成员与账户，可关联原预算；余额已含历史不重复扣款，预付款消费只冲预付资产 |
| 投资与证券 | 研究和复核不交易；已发生买入/增持/部分卖出/清仓在网站专用入口核对，并同步相应银行现金及手续费 |
| 资产与目标 | 家庭自定义类别，金额排序，目标自由组合且不重复覆盖；用户未确认的默认目标不冒充个人目标 |
| 养老金 | 受限资金账户，分资金与底层产品；内部买卖回款留在账户，不当普通银行现金，不重开年度缴费额度 |
| 周期 | 规则月金额展示与实际到期排期分开；默认不自动过账，不追补历史；当月实际与预计分别列示 |
| 月报与预测 | 读取完整已过账分录，开账、转账、贷款本金与收益分开；历史归档不可变，年度不重复累加同月版本 |
| 日历 | 已批准消费与投资复核按日期展示；待审批不进正式日历；取消释放预留并保留实际付款和历史 |
| 会员权益 | 核对有效期、人数、条件与额外费用；已购成本不重复算旅行增量开销，未知等级不猜折扣 |
| 展示 | 首次打开/刷新默认隐藏金额；历史研究可收起且保留筛选；小屏、长表单、弹窗和说明保持可读 |
| 插件接入 | 统一打包与连接检查已有本地实现记录；平台注册、分发、实际授权和iPad安装另验，不把入口文件安装当MCP已连接 |

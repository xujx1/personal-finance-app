# 个人养老金作为受限投资资金账户

本轮根据用户澄清补充P001–P007：个人养老金在账户内可以投资，含宽基基金、养老保险等；受限的是向普通银行提取，并非禁止投资。两张产品目录仅作能力说明，不作为已购买产品登记。

| 编号 | 要求与实现 |
| --- | --- |
| PI001 | 保留一个养老金资金账户，分别展示账户内可投资余额、产品市值、账户总资产、本年缴费/额度、持仓未实现收益及本站记录的卖出收益。账户内资金可投资但不能计入日常银行现金、预算备款或现金预测。 |
| PI002 | 账户内买入可选已有持仓或新产品；产品种类支持养老基金、保险、存款、其他养老产品。基金分类由本家庭真实资产类型选取，含宽基指数基金；代码可空，不推测份额和实时净值。目录截图不自动新增持仓。 |
| PI003 | 内部买入扣养老金内余额并增加产品持仓；卖出/赎回款只回该账户，普通银行不变。全额卖出核对原完整持仓，部分卖出须明确对应账面价值和成本；不能伪造份额或税务收益。仅记录平台已完成且未重复包含的成交，本站不操作购买。 |
| PI004 | 内部买卖不增加年度缴费，已满12000元缴费额度仍可用账户内资金投资。外部银行充值沿用原年度校验与同成员限制。内部投资不接收任何外部银行账户字段，不能借卖出提现。 |
| PI005 | 产品稳定ID用于后续买卖，旧无ID持仓确定性兼容且避开现有ID，新增行用UUID。名称/ID重复拒绝；产品分类归属本家庭、启用且种类匹配，仍用于养老金的类别不能停用。改名不改关联。 |
| PI006 | 所有操作原子、幂等并保存pension_trade审计文档；无总额变化的内部转换不伪造账目，手续费和相对账面的差额才产生PENSION_BUY/SALE分录。卖出收益按净成交额减对应成本；资产分录按净成交额减对应账面价值，两种口径明确区分。 |
| PI007 | 快照不能早于最近内部交易，也不能重写本站已记录卖出收益；原缴费下限、固定归属、家庭隔离和只读限制继续生效。产品分类用于账户明细与研究，总目标仍按养老金账户类别纳入，不把底层产品再登记为独立资产重复累计。 |
| PI008 | MCP资产草稿与Skill支持产品id、kind、assetTypeId、code和可选realizedProfit等字段，金额单位明确；网站核对可维护产品种类与分类。账户内实际买卖由网站专用入口核对，账户内交易历史可展开。默认脱敏和手机布局保留。 |

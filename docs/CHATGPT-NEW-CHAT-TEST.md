# 用新的ChatGPT会话测试家庭财务中心

建议新开ChatGPT会话测试完整插件；这样可以同时验证当前会话是否拿到了工作流、工具目录和登录权限。Codex的npm安装只安装本机入口，不代表ChatGPT客户端已经采用同一入口。

1. 在ChatGPT新建会话，选择已连接的“家庭财务中心”。若工具目录仍旧，先在插件设置刷新工具；登录和家庭归属沿用原账户。
2. 先说：“请使用家庭财务中心，读取当前工作流、资产类型和资产目标，说明目标选择的范围、金额单位和本月积累目标；先只读取，不保存或修改。”
3. 预期：调用get_skill_bundle、get_financial_context，能看到服务端初始化及家庭自定义的类型。目标金额、范围以当时账本为准，主币单位与分不能混淆；自选目标不能拿全部非房产资产当完成额。
4. 再在同一会话描述旅行或购物，调整费用后要求保存预算草稿。预期：ChatGPT分析/搜索→submit_finance_draft(kind=budget)→网站外部草稿→核对→有效家庭成员本人审批→预算与生活日历。提交草稿不付款。
5. 资产测试可提供已持有的资产截图，先核对真实类型、成员、币种及是否已登记，再保存已有资产草稿。实际新买入或清仓仍在网站核对真实成交与现金账户，不能用开账草稿替代。
6. 月度总结先get_monthly_review_context再提交带basisFingerprint草稿；周期归并先完整list_transactions和get_recurring_candidates，网站采用后autoPost=false，原人工规则保留。

记录实际会话的工具结果、草稿ID、网站处理结果及异常。搜索证据、报价、库存、识图和分析质量必须从真实会话单独判断，不以本地结构化样本代替。

依据：[OpenAI官方插件连接与测试说明](https://developers.openai.com/plugins/deploy/connect-chatgpt)。官方建议安装插件后启动新会话，分别验证MCP及完整插件体验。

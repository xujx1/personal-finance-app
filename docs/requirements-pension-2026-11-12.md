# 个人养老金资产与年度缴费

公开版只保留业务契约，已移除个人截图明细、产品名称、实际缴费、领取年龄、账户标识和采用回执。年度参数及个人规划由各家庭在授权环境中核对；本文不作现行政策或法定领取资格判断。

| 编号 | 要求 |
| --- | --- |
| P001 | 内置personal_pension类型，账务性质other；读取补齐旧字典，不删除或重写原类别，可按需纳入自由目标组合。 |
| P002 | 每名具体成员独立账户；资金和底层产品构成同一账户总资产，不重复计入。不能设家庭共用、转给其他成员或借身份合并归属。 |
| P003 | 展示受限状态、个人规划、年度额度/实缴/剩余额度和持仓价值/成本/收益。未知份额、代码、净值或资格不猜测。 |
| P004 | 已持有快照的账户总额、产品价值及资金余额精确核对后OPENING开账；不当收入、不重复扣银行，不推断往年或未来缴费。 |
| P005 | 实际充值核对到账、快照覆盖、同成员银行资金、日期、年度剩余额度与幂等；是内部资产转换，不当消费，不自动产生未来充值。 |
| P006 | 普通变现、重新分类或清除年度资料不能解除受限、转移归属或重开额度；快照不能覆盖新的已确认事实。 |
| P007 | MCP资产草稿金额使用元字符串，服务端核验成员、年份、类型、币种及合计；核对采用才开账，重复登记拒绝。 |

后续[账户内投资](requirements-pension-investment-2026-11-12.md)允许内部投资和赎回，仍禁止向普通银行提取；[底层分类](requirements-pension-classification-2026-11-12.md)约束展示与目标去重。

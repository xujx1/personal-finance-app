# 银行存款分类更正

[English](DEPOSIT-CLASSIFICATION.en.md)

在资产现状选择账户的“调整”，银行现金和银行定期存款之间可以更正分类，包含家庭自定义的同性质分类。该操作保留账户ID、金额、币种、归属和历史流水，不新增资金或生成转账。

更正分类不能同时更改金额或归属，也不能更改归档账户。已发生实际收付款或仍用于周期收付的账户须先核对相关业务；实际存入定期或到期转回应通过内部转账记录，不能把实际资金流动伪装成分类更正。历史流水检查覆盖全量账本，不只检查页面近期记录。

仅知道到期年份时，可填写年份并保留具体日期为空。缺失起存日、到期日、利率或银行资料时标记待完善，不生成虚构日期，不计算预计利息；定期本金不计入可花银行现金。新登记定期存款仍使用原来的完整资料校验。

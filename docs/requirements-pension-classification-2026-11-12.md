# 养老金持有账户与资产分类

用户确认个人养老金是不可提取的投资资金账户，内部可配置基金、债券等产品。

- PA001：资产页按底层产品分类展示养老金持仓；标注持有账户、成员、不可提现。账户总额、内部现金、产品市值分别显示，分类金额不重复计算父账户。
- PA002：支持持有账户筛选；养老金内余额单列，不混入银行现金。现有三项产品仅按已知资料归为基金，不猜测细分类。
- PA003：持仓可单独修改种类和家庭分类，改分类不能修改金额、成本、缴费、银行现金、快照日期或生成资金流水，保留审计。
- PA004：基金、债券、存款、保险及其他产品均可在养老金内记买入/赎回；回款只进养老金内余额。分类行操作路由到原账户，禁止当普通资产变现或转出。
- PA005：总览分布、MCP研究和目标使用相同底层分类。目标若明确选择养老金账户整体，先按整个账户归入该目标，内部持仓不再次归入其他目标；旧目标不被重写。
- PA006：保留家庭隔离、成员归属、只读限制、年度额度、不可提现与原有交易校验。未知净值、数量不虚构。

实施顺序：先写投影及改分类失败测试，再实现服务端、页面和MCP/Skill；运行代码检查和隔离E2E，发布后只做三项已知基金的分类维护，核对所有金额和实际流水不变。

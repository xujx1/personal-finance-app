# 家庭财务体验、审批与安全（2026-11-12）

对应本轮15项需求，延续既有家庭归属与ChatGPT登录体系。

| 项目 | 实现与验收口径 |
| --- | --- |
| 1 汇率提示 | 总览、资产页顶部横幅移除，估值详情保留真实来源日期 |
| 2 家庭审批 | AI采纳后发起审批，所有有效登录成员本人同意才为正式预算；记账档案不代替登录审批；更改清单、金额、日期或归属重开审批 |
| 3 费用小票 | 移除左侧长表单，右侧紧凑编辑数量、单价、名称、纳入/移除，行程详情展开，精确到分实时重算 |
| 4 酒店餐厅 | 支持具体商家、候选选择、自定义名称；选择候选同步金额；编辑后重新AI复核 |
| 5 价格真实性 | 区分估算、用户提供、检索参考；检索参考须有服务器取得的来源、查询时间和匹配的人民币价格摘录；无证据不标实时报价，商品比价亦然 |
| 6 投资展示 | 关键结论置顶，正文、来源和完成节点展开查看；切换历史恢复收拢状态 |
| 7 股票证券 | 账户表格保留列宽，报价详情收拢，持仓明细可横向滚动；行情按北京时间自然日缓存一次，保留原始报价时间，失败当日不反复请求 |
| 8 房贷资料 | 编辑和AI登记支持年利率、开始及结束日期，验证利率和日期先后；未知资料留空 |
| 9 提前还款目标 | 2027-01-09预算180000元，预计本金179739.09元、利息260.91元，期限不变减少月供；只作计划。总览展示全部未付计划超过人民币银行现金的备款缺口，已付/预付不重复计算 |
| 10 图片入口 | 独立导航移除，现金流水内保留图片导入及逐笔核对入账 |
| 11 周期布局 | 规则表单对齐，确认选项独立成组，列表与候选证据适配手机 |
| 12 非工资收入 | 现金流水手动记实际收入、支出和图片确认，必须明确成员及账户；15000元月目标随本月人民币业务新增积累变化，排除开账与校正，不因缺少上月期初而完全禁用 |
| 13 现金预测 | 当前人民币银行现金＋周期收入－周期支出－计划尚需现金；未批准计划保守纳入并标待确认，证券房产不视为可用现金 |
| 14 AI周期导入 | 完整多月历史按成员、账户、方向、相近日期/金额归并；AI仅辅助说明已验证候选，不能改金额或账户；显示原分录证据，确认才保存，从未来日期起生效，默认不自动入账 |
| 15 家庭数据安全 | 财务读写、审批、命令状态、图片、附件、研究、MCP及行情缓存按家庭隔离；移除成员旧会话/进行中请求复查权限；普通成员仅能提交本人审批，不能修改其他财务 |

审批成员加入、移除或重新加入会使需要确认的预算重新核对。仅创建/撤销邀请、修改家庭名称不会清空同意票。未来还贷实际发生时通过贷款本金与利息分账记录，部分还贷保留计划剩余备款。

旅行、餐饮和商品费用并未接入交易平台的实时库存/订单报价；只有实际抓取的价格证据可以称为检索参考。特定入住日期、房型、人数、税费和余票仍以平台最终报价为准，不能将模型估算称为已核实成交价。

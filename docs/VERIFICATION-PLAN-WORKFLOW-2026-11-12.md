# 消费计划全流程验收

日期：2026-11-12。分支：codex/chatgpt-mcp-skills。

## 最新业务流程

1. ChatGPT通过MCP保存消费草稿，仅在研究记录核对。
2. 发起人采用后进入预算与大型支出，等待全部有效家庭登录成员本人审批；保留分享审批和导航提醒。
3. 审批通过才进入生活日历，覆盖旅行、餐饮、购物和还贷等计划。方案变更触发重审时退出日历，重新通过后恢复。
4. 实际发生后从日历打开计划，在详情录入真实金额、实际日期、付款成员与现金账户，核实后提交。
5. 同一次账本操作生成关联流水并更新对应余额：消费减少银行现金，预付款保留为资产，消费冲抵预付不再扣现金，实际还贷按本金/利息分录更新贷款和现金。

审批通过、日期到来和浏览页面均不自动入账；预算金额不是实际消费。实际日期不得在未来。投资复核日程保持独立，不执行证券交易。

取消、结束或待重审的计划不允许新增付款，但已有预付款仍可核实消费或到账退款。退款回原付款账户，避免遗留无法处理的预付资产。

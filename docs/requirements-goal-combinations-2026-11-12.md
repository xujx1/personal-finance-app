# 按基础资产类型自由组合目标

本轮替代B003中固定组合下拉和资产类型“归入目标组合”的交互，保留旧目标兼容。

| 编号 | 要求与实现 |
| --- | --- |
| G001 | 目标设置每项支持自定义组合名称、人民币金额，勾选一个或多个本家庭基础资产类型。不固定四个组合，支持增删，最多20项。原四组合仅作旧数据兼容及可编辑起始建议。 |
| G002 | 选项来自家庭资产类型字典，新增类型自动出现在可选项，改名同步展示。组合保存真实类型ID集合，改名不改关联，新类型不自动纳入；同类型新账户自动按所选类型统计。 |
| G003 | 同一类型只能计入一个目标，未选类型另列且不计进度。组合名称/ID不能重复，类型必须属于本家庭、启用且非房产/贷款/预付款；后端逐项校验，无账户时也防重。仍被目标引用的类型不能停用。 |
| G004 | v2/v3旧目标读取保留原统计口径，不在发布或读取时自动迁移。编辑页提供类型建议并明确待切换，旧目标切换须在表单核对确认后保存。若旧资产分类造成建议交叉，须调整重复勾选才可保存。新数据v4持久化名称和显式类型集合；金额仍整数分，接口输入元字符串。 |
| G005 | MCP setup/goals及网站建档核对支持targets:[{name,assetTypeIds,target}]，可核对名称、金额与类型后采用；旧scope草稿兼容且不能与新格式混用。财务依据返回每组合的真实类型集合、金额和完成率。onboarding提供goalCombinationTypes，Skill引导自由组合；新资产类别不再要求指定固定目标组。 |
| G006 | 网站资产类型维护移除固定组合下拉。沿用现有家庭隔离与本人核对，未授予新权限；保存目标只改目标配置，不改资产、银行余额或流水。桌面/手机均可操作。 |

## 验证边界

新增失败先行的领域/接口测试6项：多类型金额统计、新账户与类型改名、新类型不自动加入、重复/跨家庭/停用/不适用类型、引用停用保护、命令无财务变动、MCP新旧格式兼容。

全量612项测试、类型检查通过。资产类别与目标专项10项浏览器测试通过，包含MCP提交自由组合→网站修改名称→核对采用→财务依据和总览展示；另跑15项建档E2E，兼容旧scope路径。测试用SQLite和独立模拟家庭，不调用真人ChatGPT模型，不向正式账本写测试数据。

独立只读审查无实质问题，45项定向测试通过；额外验证v2读取与编辑建议不写数据，提交v4草稿不切换目标，采用后才在原目标ID更新，且不改变账户或分录。

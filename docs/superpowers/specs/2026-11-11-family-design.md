# 家庭可见权限与初始化

用户已选定：保留个人归属，加入同一家庭后均可查看；继续自主开发，无需逐项确认。

沿用现有Sites登录、D1和页面。采用显式家庭成员关系及每家庭独立book/dataset，所有财务HTTP、AI、附件、行情和MCP入口先授权，再获取当前家庭范围。不能仅修改导航或Sites名单冒充家庭隔离。现有personal账本仅绑定受信任站点所有者，邮箱从Sites所有者配置取得；没有配置或成员资格时默认拒绝，不允许首个陌生登录者领取旧账。

默认权限是管理员维护家庭和账本，邀请成员只读；保留资产归属标签，不合并家人尚未实际转入的资金。按用户最新更正：邀请不绑定邮箱，以随机一次性链接邀请；接受时绑定受信任的ChatGPT登录subject。链接7天有效、一次使用，数据库只保存随机token的hash，链接使用fragment，不包含账本内容。支持改名、邀请、撤销、加入、成员移除、自行退出和管理员转移。退出/移除立即阻止后续请求；长期操作最终写入再次校验成员资格。

Sites仍保留当前私密名单。应用邀请与平台放行是两层权限；无收件邮箱时不实际发邀请、不扩展访问。原有私密名单会阻挡新家人直接打开链接；完成应用权限后，登录/邀请入口可开放而财务API继续仅成员授权，此平台入口调整需单独明确后执行。不能让整站公开以绕过平台限制。

可选方案：仅Sites共享不能区分家庭，弃用；每用户独立库并在客户端拼接会破坏共同月报和预算语义，弃用。采用家庭book和不可由客户端任意选择的服务端范围，复用现有双分录、幂等、修订和报表。

初始化使用独立的管理员入口，一次性导入空账本；明确来源日期和快照状态，不依赖当前不可用的模型额度，不恢复通用未审批新增资产入口。通过同一原子批次写开账分录、资产元数据、导入收据及审计；相同请求重试不重复入账，非空账本拒绝初始化覆盖。实际资料只经本人页面传入，不嵌入源码、构建或公开示例。

证券快照与股数乘参考价不符时保留原账面值并标待核对，不编造差额现金。赎回中仍为权益，工资已含余额不重复入账，预约还款不减本金；未实际转入的家人资金不计可花现金。

验收：两家庭隔离及猜ID、只读成员写入、过期/撤销/重复邀请、并发接受及移除、旧会话、跨域写入、所有生产路由授权覆盖；初始化原子性/幂等/日期/归属/分类；真实SQLite及Worker、隔离浏览器E2E，正式部署后本人页面核实。实际第二账号加入依赖家人邮箱及平台放行，测试与该外部步骤分别报告。

# 基金股票买入与清仓

用户要求基金、股票增加买入和清仓，并对应调整银行现金。沿用已有asset.trade复式分录，不执行券商或银行交易。明确资产后的买入/清仓按钮，基金与股票页面可记录首次买入；现有房产等通用买卖与转账保留。

买入时用户确认成交已完成，选择资金成员及同币种银行现金账户，填写成交总额（不含手续费）、手续费、成交数量和日期。既有持仓增持，首次买入创建持仓并扣现金，同一事务执行；不得以OPENING登记伪装新收入。清仓由服务器取得全部账面余额及全部已知数量，按真实成交总额减手续费入银行；只设置清零状态并隐藏，历史保留。

不以行情报价代替成交价，不自动换汇，不扣其他未选账户。旧数量未知时保留总量未知，不拿新增份额当总份额；清仓后可在历史中再次买入。重复请求幂等，余额不足、跨家庭、普通成员、未来日期和币种/成员错配拒绝，失败不留下新持仓或分录。实际交易日期不晚于今天且不应早于已覆盖的现金或持仓快照。

实现选择：复用asset.trade并提取独立服务，新增mode=buy/liquidate与newAsset分支；不新增一个旁路余额接口。mode需要actualConfirmed，legacy通用买卖协议保留。清仓不信任客户端传来的余额和数量。按用户此前授权直接开发，不再逐项确认。生产只读验收，不执行真实清仓或买入记账。

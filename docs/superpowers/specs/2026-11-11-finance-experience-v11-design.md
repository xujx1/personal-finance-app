# 财务中心18项体验修订

用户已授权直接开发，不逐项确认；本轮18条优先于旧文档，尤其AI节点展示与旧隐藏节点要求相反，以本次要求为准。

总览只展示资产、未来支出和目标，不嵌入生活日历；目标默认400万元、不含房产，四大类各100万元：股票、银行存款+国债、宽基、黄金贵金属。总目标与月目标使用进度环图，未知月目标不编造完成率。设置按大类维护，避免逐只基金配置。

AI消费和投资统一：左侧输入自然语言，右侧分节点展示真实读取进度、简要结果和逐步分析。无手选消费类型或初始人工清单按钮。安全HTML语义渲染标题、列表、表格，拒绝执行模型HTML/脚本。旅行行程与费用可编辑联动；购物有可核验来源的比价；历史列表固定在下方，5条/页并支持模糊搜索。

资产分类页签显示当前类别总额，清仓与归档账户默认隐藏但保留历史。新增银行定期存款与银行、起存日、利率、到期日、预计利息；行情读取使用公开腾讯/基金接口并保留来源时间、缓存与失败状态，查看不改账面或现金。

取消提醒产品入口。周期规则按已知资料初始化，缺失关键资料保留待核对，不把银行未发生业务当实际入账。图片识别必须实测草稿确认到流水/现金/幂等；正式数据只生成草稿，不模拟真实扣款。家庭权限、个人资产归属与预算确认门禁保持。

分工接口：GoalOverview({state,valueCNY}), SavingsGoals({state,onSave,valueCNY})；FinanceApp由资产分支负责整合。AI根代理负责。周期/图片分支不编辑finance-store.ts，资产分支不编辑finance-extensions.ts或jobs.ts。

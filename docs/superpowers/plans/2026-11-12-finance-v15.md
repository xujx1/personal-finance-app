# Finance v15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Continue without item-by-item confirmation per user instruction.

**Goal:** 完成15项体验、审批、备款、预测与安全需求。
**Architecture:** 现有Worker/D1服务端权威校验，React紧凑交互；新增纯领域模块供界面和服务端共用。
**Tech Stack:** React19、TypeScript、Worker、D1、node:test、既有浏览器脚本。
**Spec:** docs/superpowers/specs/2026-11-12-finance-v15-design.md

## Global Constraints

保留原18账户；不代家庭成员审批；不执行实际银行还款；保持用户既有分支和未提交文件；仅发布经测试的脱敏源码，不导出秘密或数据库。

## Review Focus

- 普通成员确认自己审批，不能绕过只读限制做别的写入。
- 旧审批被方案/金额/日期/归属变更失效，不能用旧命令或同意票批准新方案。
- 商家名称不能使估算自动升级为核验报价；查询失败保留来源状态。
- 预付款与贷款预算避免重复扣款，工资之外收入计入月目标。
- 跨家庭猜测ID、命令key、缓存及移除成员必须拒绝。

# AI消费建议与预算确认 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 恢复可见的AI消费助手，评估旅行/购物想法，并由本人确认生成预算。

**Architecture:** 沿用已批准技术方案7.1/7.2和现有账本。独立资金测算函数；服务端New API适配器；建议作为documents保存，确认通过同一个原子命令写预算。模型不可用时明确显示规则测算，不冒充AI。

**Tech Stack:** 现有React/TypeScript、D1；本地沿用SQLite适配器；不增加npm依赖。

**Spec:** 在线技术方案v1.1，page_7318386ab3248191bb231cbe0324c01f。

## Global Constraints

- 密钥仅服务端环境变量，浏览器只获取配置是否完整；不读取其他项目密钥。
- 建议和预算确认不生成分录、不改变现金；真实付款继续走原付款接口。
- 输入金额为人民币十进制字符串；不把单笔工资当月收入，不将外币证券当国内可用现金。
- 保存建议后账本发生变化，则确认失败，要求重新评估。
- 当前没有模型配置；本地测试可以验证规则测算和模拟模型接口，不能宣称真实模型联通。

## Review Focus

1. 缺少生活费、月收入或应急金时，不能给出无条件可花结论。
2. 预留与同一预算的待支出不能重复扣减；已有计划已支付部分也不能再算未来支出。
3. 重复确认同一建议只能产生一个预算；不能绕过陈旧建议检查。
4. 模型无效输出、超时、密钥错误不能回显密钥或冒充有效AI结论。
5. 本地重启保留用户正在体验的模拟账本；生产入口不引入本地模拟身份。

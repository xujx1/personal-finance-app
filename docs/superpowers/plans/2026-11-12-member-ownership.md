# 按成员管理实施计划
Spec: docs/superpowers/specs/2026-11-12-member-ownership-design.md
1. 成员目录、别名、归属快照与筛选领域层，拒绝跨家庭与未归属静默猜测。
2. 服务端资产/预算归属、记账档案、现金成员匹配、历史固化以及退款转账/预付款/周期/图片一致性。
3. 页面成员筛选、成员+账户明确选择、登记/预算归属和家庭记账档案维护。
4. A/B隔离集成测试与E2E、家庭权限回归、复核、正式发布与真实数据不变核对。

测试重点：B记账不改A现金；A↔B转账两边可查但不算收入支出；退款原账户；旧交易归属重分配后不改；伪造其他家庭成员ID/错误现金成员拒绝；只读家庭成员不能写；现有AI审批、周期和图片幂等门禁保留。

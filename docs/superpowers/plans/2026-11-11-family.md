# Family Access Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task; user requested autonomous continuation.

**Goal:** 家庭管理、ChatGPT账号邀请链接、家庭范围读取与保留归属的资产初始化。

**Architecture:** 家庭成员授权后创建带范围的D1依赖；store从范围取得bookId，所有对象继续由dataset限定；家庭表和原子权限检查保护成员撤销及写入。

**Tech Stack:** Existing TypeScript/React/Vinext, Cloudflare D1, Node SQLite tests.

**Spec:** docs/superpowers/specs/2026-11-11-family-design.md

## Global Constraints

保留原私密访问；保留个人归属；管理员写、家人读；数据及凭据不进源码；不依赖AI进行初始化；不自动发送邮件、不做交易。既有工作区修改不清理，源代码检查点用于隔离构建发布。

## Review Focus

- 受信任旧账绑定与无配置默认拒绝。
- 两家庭猜测ID、附件与MCP不能串读。
- 同时撤销/接受邀请和长期请求后的权限变化。
- 转移管理员后旧会话写入与旧管理员重新领取旧账。
- 初始化失败或重复提交不能留下部分资产。

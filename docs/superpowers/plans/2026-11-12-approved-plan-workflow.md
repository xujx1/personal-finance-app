# 已审批计划执行流程

按用户最新确认，消费计划统一为研究记录核对采用→预算与大型支出家庭审批→审批通过进入生活日历→本人核实实际消费→生成关联流水并更新对应账户。此规则覆盖此前“待审批也展示日历候选”的约定，审批分享与预算导航提醒保留。

- [x] 日历投影仅接受正式APPROVED且家庭审批未待定的预算；旅行、餐饮、购物、提前还贷等均可进入。投资复核独立保留，不代表交易。
- [x] 日历移除待审批筛选与图例；预算仍保留分享审批和待本人数量。
- [x] 计划详情提供实际消费付款、预付款、消费抵扣、预付款退款及实际贷款还款，选择真实成员/账户、实际金额日期并确认，读取阶段不记账。待批/结束计划不展示新付款表单。
- [x] 不将计划预算或研究价格当作实付；普通消费减少付款账户现金，预付消费不重复扣现，还款区分本金与利息。实际日期不允许未来。
- [x] 更新需求及消费Skill说明；新增整条隔离HTTP/浏览器回归，验证发起人采用、另一家人审批、日历、实际记录、流水与余额，以及重复提交/外人访问/预付不重复扣现。
- [x] 类型/相关单元与浏览器验证、生产构建，发布后只读核验，不动实际财务数据。

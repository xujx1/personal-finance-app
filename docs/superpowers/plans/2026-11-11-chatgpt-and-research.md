# ChatGPT OAuth 与 MCP 双入口实施计划

**用户已明确要求**：站内官方ChatGPT OAuth、ChatGPT通过MCP操作站点均支持；补旅行行程/预算、购物识别检索比价、理财研究。

## 边界与接口

- 网站登录继续沿用Sites，ChatGPT套餐授权是额外AI连接，不引入家庭账号体系。
- 当前本地个人项目采用官方动态注册+127.0.0.1回调。部署后的注册客户端或VM迁移遵循官方支持范围，不把动态注册回调改成任意HTTPS地址。
- OAuth使用PKCE/state/nonce、验证ID token签名/iss/aud/exp/nonce和授予scope；令牌仅服务端加密保存，不写入财务审计、浏览器或源码。
- OAuth推理使用Responses API的store:false、stream:true；只有response.completed才视为成功。模型列表来自授权账户，不把列表当作推理权限证明。
- MCP优先Sites原生private插件，POST /mcp；只暴露查询、研究请求及方案草稿，不开放审批、付款、证券交易和任意账本命令。
- 外部方案保留来源、检索时间及人工确认状态；旅行/购物可转预算草稿，理财研究单独保留，不转消费支出。
- 搜索/图像识别/以图搜同款单独工具接入。当前没有真实联网研究证明，不生成虚构报价或假成功。

## 任务

- [ ] MCP：受保护的上下文/研究请求查询，提交结构化方案；协议与权限测试。
- [ ] OAuth：加密凭据、授权与回调、刷新、模型列表、Responses SSE；模拟协议与安全测试。
- [ ] 页面：AI连接管理、MCP研究收件箱、资产贷款理财研究快捷入口；ChatGPT provider选择。
- [ ] 本地重启保留账本，完整回归/E2E，明确真实OAuth授权和公网MCP验证阻断。
- [ ] 更新技术方案、需求和源码下载包。

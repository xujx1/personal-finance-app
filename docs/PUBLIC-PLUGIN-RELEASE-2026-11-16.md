## 付款与地区门槛

发布控制台要求当前组织添加有效付款方式并设为默认，才能继续组织验证。账户持有人目前只有中国大陆发行的银行卡。官方要求付款卡由支持地区银行发行，中国大陆不在当前API支持名单中；换大陆银行或卡组织标识不能解决发卡地区限制。此路径目前受阻，不要求用户反复绑卡、充值或购买第三方代付。

这是开发者平台验证和付款资格要求，不要求财务网站改回模型API调用。当前方案由ChatGPT完成分析、搜索、图片理解和总结，MCP保存待核对草稿；ChatGPT订阅与API组织分别计费。

添加付款方式提示不等于已确认必须购买API额度或支付上架费；后续充值、自动充值或付款条款须另行核对。官方说明API绑卡可能有临时预授权，不能承诺整个过程没有冻结或费用。

## 可继续使用的范围

- 既有账号已接通的私有插件和受控网站可按现有权限继续使用，不依赖公共上架完成。
- 网站保留家庭管理、本人已有资产录入、计划修订/审批及实际收支核对，不执行银行付款或证券交易。
- 家人独立ChatGPT连接须核实其账号、地区、套餐/工作区权限及实际安装授权入口；私有连接、工作区共享和移动端不保证对所有账号开放，也不能绕过平台资格要求。
- 网站邀请不等于ChatGPT插件共享；每位接收者仍需具备自己的安装、连接和家庭访问权限。第二真实账号和物理iPad继续标记待验收。

## 家庭成员自定义 MCP：OAuth 实测阻塞

2026-11-16 在 ChatGPT 网页的“添加自定义 MCP 服务器”中，用当前站点 `/mcp` 地址完成只读自动发现检查。未创建新插件、授权新连接或修改站点访问范围。

| 检查 | 结果 |
| --- | --- |
| 授权服务器 | 自动发现 `https://auth.openai.com`；授权与 Token 地址可发现 |
| 动态客户端注册 DCR | 界面显示不可用，未发现注册 URL |
| 客户端标识符元数据 CIMD | 界面显示不可用，服务器未声明支持 |
| 注册方式 | 默认“用户自定义 OAuth 客户端”，需要有效客户端 ID |
| 回调地址 | 页面为该次连接生成独立地址；应登记接收者实际页面显示的完整地址，不复用维护者临时测试地址 |
| 现有 Sites 插件 | 当前账户只读 `get_skill_bundle` 调用成功；不证明新的自定义连接可用 |
| 家庭成员连接 | **BLOCKED**：没有已注册并验证适用于该连接的客户端配置，未完成授权、工具发现或第二账号测试 |

本站的 `auth_client_id` 是 Sites 托管配置的一部分，不能据此假定它允许另一个自定义连接的回调地址。插件 ID、家庭 ID、模型 API Key 和 Sites 服务访问令牌均不能替代 OAuth 客户端凭据。没有依据将 Token 认证方法、作用域或密钥留空规则写成已验证安装步骤。

目前可用 Sites 工具未提供 OAuth 客户端注册/回调白名单修改能力；已检查的私有插件管理页面也没有这一入口。官方独立 Sign in with ChatGPT 客户端申请仍为限定合作方入口，不能把开源本机推理客户端的动态注册流程用于此托管 MCP 连接。

解除阻塞需要平台为自定义 MCP 提供合法客户端配置并登记实际回调与资源，或者提供可供受邀成员安装的受支持插件分发方式。仅在完成后，才能实测授权、工具发现、家庭范围隔离和 Skill 读取，再交付成员安装说明。此项与公共目录付款/身份验证分别记录；不承诺添加银行卡即可解决。

本轮未修改业务代码、伪造发现元数据、替换托管登录、公开站点或绕过身份检查。仍缺 OAuth 客户端登记及第二真实账号授权，不能标记“安装完成”。

## 公共上架恢复条件

1. 账号与组织符合平台支持范围并完成合法验证，身份及付款材料由持有人直接提交官方平台，不进入聊天或源码。
2. 确认真实发布者信息、支持渠道、隐私政策及服务条款。
3. 准备独立审核身份和模拟家庭，不提供真实家庭账本、绕过令牌或生产凭据。
4. 使用允许公开提交的插件包，完成MCP域名/OAuth及工具、Skill扫描。官方不接收带apps/.app.json引用的公共提交包；公共包需声明远程MCP地址。现有打包器支持两种模式，本地应用绑定包不能标为已具备送审资格。
5. 审核身份实际运行正反向场景、准备演示与审核资料，送审通过后才发布。

npm安装、打包成功、站点部署、单次读取不能代替这些步骤。公开上架保持BLOCKED，不扩大站点范围，不改写旧验收结果。

# 基金股票买入清仓与银行现金联动

日期：2026-11-12。对应用户最新要求：基金、股票增加买入和清仓，银行现金同步调整。沿用当前开发分支codex/chatgpt-mcp-skills。

## 现行要求

- S001：基金、股票资产行明确提供买入、清仓按钮，保留原部分卖出/赎回和持仓成本入口；资产页可记录首次买入新基金或股票。
- S002：买入必须核对真实成交总额、手续费、本次数量和日期。已持仓则增持，新持仓则与现金扣款一同创建；银行减少成交额加手续费。首次买入产生ASSET_BUY而非OPENING。
- S003：清仓由服务端取得全部账面余额及已知份额，银行增加实际成交额减手续费。清仓后默认隐藏但不删除原资产和流水；历史可查，零持仓可再次买入同一账户。
- S004：明确选择付款/到账成员及其同币种银行现金账户，仅更改所选账户。人民币与美元分开，不自动换汇。原持仓数量未知则保留总量未知，仅记录本次买入数量；清仓不编造份额。
- S005：保存前展示银行现金影响，修改金额/费用/账户等会清除原确认；本人确认实际成交、收付款及未被余额重复包含后才保存。余额不足、超限、未来/覆盖日期、成员币种错配、跨家庭和只读写入拒绝，失败全回滚，原请求重试不重复记账。
- S006：现金流水、资产汇总、目标和月报读取同一复式分录，资产转换不冒充消费；费用和损益分列。本次只登记已经发生的事实，不向银行券商下单，也不在生产写测试交易。

此要求新增的是网站真实交易核对记账能力，不恢复站内AI模型，也不增加MCP代交易或代付款工具。已有资产登记仍可用ChatGPT草稿；实际新买入需要扣现金时，必须走买入记录，不以已有资产开账代替。
